## low: Dev and start scripts require undeclared global CLIs

id: fnd_sig-feat-library-4f1e5a63f1-477b_a55306a37e
category: build-release
confidence: medium
triage: risk
status: open
feature: Node package visitenkarte (feat_library_4f1e5a63f1)

evidence:

- package.json:5-7 (scripts.dev)
- package.json:18-42 (dependencies)
- AGENTS.md:18-20

The documented local workflow tells contributors to run `bun run dev` or `bun run start`, but the script shells out to `bgproc` and `portless` while the package manifest only installs Astro, Tailwind, Playwright, and related project dependencies. A fresh checkout that follows `bun install` can fail before Astro starts unless those user-specific CLIs already exist on PATH.

recommendation:
Either declare the required CLIs as dev dependencies or change the standard dev script to use declared tools only. If global `bgproc`/`portless` are intentional, document their installation as a prerequisite and provide a fallback script such as plain `astro dev`.

test analysis:
The linked visual tests run `bun run build` and Playwright against `astro preview`; they do not exercise the `dev` or `start` package scripts on a clean install.

suggested regression test:
Add a lightweight CI smoke check that validates all first-token package script commands resolve from declared dependencies or an explicit allowlist.

minimum fix scope:
Update `package.json` dev/start scripts and the local workflow documentation.

repro:
On an environment without global `bgproc` and `portless`, run `bun install` followed by `bun run dev`; command lookup fails before the Astro dev server starts.
